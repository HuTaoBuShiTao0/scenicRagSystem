# 洛阳景区问答智能体 - 前端项目

基于Vue 3 + Element Plus的洛阳景区智能问答系统前端界面，融合洛阳文化底蕴与现代设计美学。

## 🎨 设计特色

### 新中式美学设计
- **牡丹红主色调**：采用洛阳牡丹的深红色作为主色调，体现洛阳文化特色
- **古铜金辅助色**：使用古铜金色作为点缀，增添历史厚重感
- **宣纸白背景**：温暖的米白色背景，营造舒适阅读体验
- **传统字体**：使用思源宋体和马善政书法字体，体现文化底蕴

### 交互体验
- **流畅动画**：精心设计的过渡动画和微交互
- **响应式布局**：适配各种屏幕尺寸
- **智能卡片**：富媒体卡片展示景点、美食等信息
- **流式输出**：模拟真实AI对话体验

## 🚀 功能特性

### 智能问答页面
- ✨ 精美的欢迎首页，带有快捷操作入口
- 💬 实时对话界面，支持流式输出
- 🎯 智能意图识别（景点讲解、美食导购、天气查询等）
- 🃏 富媒体卡片展示（景区、美食、酒店等）
- 📱 响应式设计，支持移动端

### 知识库管理页面
- 📊 多类型知识库管理（景区、景点、美食、酒店、文创、天气）
- 📋 表格形式展示，支持搜索和筛选
- ➕ 支持单条添加和批量导入
- ✏️ 在线编辑功能
- 🗑️ 数据删除功能
- 📤 数据导出功能
- 🖼️ 图片上传预览

## 📦 技术栈

- **框架**: Vue 3.4+
- **构建工具**: Vite 5.0+
- **UI组件库**: Element Plus 2.5+
- **状态管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **HTTP客户端**: Axios 1.6+
- **工具库**: @vueuse/core 10.7+
- **样式预处理**: Sass 1.69+

## 🎯 核心功能说明

### 意图识别系统
系统支持以下意图类型：
- 🏯 **景点讲解**：介绍洛阳各大景区、景点信息
- 🍜 **美食导购**：推荐洛阳特色美食和餐厅
- 🌤️ **天气查询**：提供实时天气信息
- 🏨 **酒店导购**：推荐住宿选择
- 🎁 **文创导购**：介绍特色文创产品
- 💬 **客服回答**：处理用户咨询
- ❌ **拒答**：处理超出范围的问题

### 知识库结构
每个知识库类型都有特定的字段结构：

**景区知识库**：
- 景区主图、景区名称、景区类型、景区级别、经纬度、景区地址

**景点知识库**：
- 景点图片、景点名称、特色标签、关联景区、详细地址、经纬度、景点介绍

**美食知识库**：
- 店铺主图、店铺名称、店铺类型、归属景区、经纬度、详细地址、店铺标签

**酒店知识库**：
- 酒店主图、酒店名称、酒店等级、价格区间、详细地址、联系电话

**文创知识库**：
- 产品图片、产品名称、产品类别、价格、产品描述、产地

**天气知识库**：
- 日期、天气状况、温度范围、湿度、风力风向、空气质量

## 🔧 配置说明

### API代理配置
在 `vite.config.js` 中配置了API代理：
```javascript
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```

### 后端接口对接
修改 `src/utils/request.js` 中的baseURL配置：
```javascript
const request = axios.create({
  baseURL: 'http://your-backend-api.com', // 修改为实际后端地址
  timeout: 30000
})
```

## 📝 开发建议

### 添加新页面
1. 在 `src/views/` 下创建新的Vue组件
2. 在 `src/router/index.js` 中添加路由配置
3. 在导航栏中添加入口

### 添加新API
1. 在 `src/api/index.js` 中添加新的API方法
2. 在组件中导入并使用

### 自定义组件
1. 在 `src/components/` 下创建组件
2. 在需要的页面中导入使用

## 🐛 常见问题

### 依赖安装失败
尝试使用淘宝镜像：
```bash
npm install --registry=https://registry.npmmirror.com
```

### 端口被占用
修改 `vite.config.js` 中的端口号：
```javascript
server: {
  port: 3001, // 修改为其他端口
  // ...
}
```

### 样式不生效
确保安装了Sass依赖：
```bash
npm install -D sass
```
